# 广告集成完成指南 - v2.0 优化版

## ✅ 新版本改进

### 1. Google AdMob 集成
- **依赖添加**: `google_mobile_ads: ^5.1.0` 已添加到 `pubspec.yaml`
- **Android配置**: `AndroidManifest.xml` 已配置权限和测试应用ID
- **iOS配置**: `Info.plist` 已配置测试应用ID和网络权限
- **初始化**: 在 `main.dart` 中初始化AdMob

### 2. 广告服务 (`lib/services/ad_service.dart`)
- **激励视频处理**: 支持加载、显示、奖励回调
- **每日限制**: 每天最多3次广告观看
- **测试广告ID**: 使用Google提供的测试ID，避免违规
- **错误处理**: 完整的加载失败、显示失败处理

### 3. 状态管理 (`lib/providers/ad_reward_provider.dart`)
- **广告奖励状态**: idle, loading, watching, rewarded, failed, limitReached
- **剩余次数追踪**: 实时显示今日剩余广告观看次数
- **Provider集成**: 与Riverpod完全集成

### 4. UI组件更新 (`lib/widgets/ai_reading_widget.dart`)
- **智能按钮**: `AIReadingButton` 根据解读类型自动切换模式
- **每日抽牌**: 永久免费，直接显示正常AI解读按钮
- **付费解读**: 1卡/2卡/3卡解读需要观看广告解锁
- **用户友好**: 显示剩余次数、错误提示、观看进度

## 📋 商业模式实现

### 免费层（广告支持）
- ✅ **每日抽牌**: 永久免费
- ✅ **额外解读**: 1卡/2卡/3卡解读通过广告解锁
- ✅ **每日限制**: 最多3次广告观看
- ✅ **成本控制**: 使用测试ID，上线前需替换为真实广告单元ID

### 用户体验流程
1. 用户点击"1卡解读"等付费功能
2. 显示"广告を見てAI解読を取得 (3回残り)"按钮
3. 点击后显示"広告を準備中..."对话框
4. 广告播放完成后显示"広告視聴完了！"确认
5. 用户点击"続ける"开始AI解读生成
6. 每日计数器自动更新

## 🚀 上线准备

### 生产环境配置
1. **更换广告单元ID**: 
   - 在 `lib/services/ad_service.dart` 中将 `YOUR_PRODUCTION_AD_UNIT_ID` 替换为真实ID
   - Android和iOS分别配置不同的广告单元ID

2. **应用ID更新**:
   - `android/app/src/main/AndroidManifest.xml`: 更新`com.google.android.gms.ads.APPLICATION_ID`
   - `ios/Runner/Info.plist`: 更新`GADApplicationIdentifier`

3. **AdMob控制台设置**:
   - 创建应用和广告单元
   - 配置激励视频广告
   - 设置广告投放策略

### 监控指标
- 广告加载成功率
- 广告观看完成率  
- 每日活跃用户的广告观看次数
- 广告收入 vs AI解读成本

## ⚠️ 注意事项

1. **测试广告**: 当前使用Google提供的测试ID，不会产生真实收入
2. **政策遵守**: 确保遵守Google AdMob政策，避免虚假点击
3. **用户体验**: 广告不应影响核心功能（每日抽牌保持免费）
4. **错误恢复**: 广告失败时应提供替代方案或重试机制
5. **数据持久化**: 每日计数器使用SharedPreferences，应用卸载后会丢失
